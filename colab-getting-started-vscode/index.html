I’ve seen this warning when installing pip with pip3. And it’s because the pip executable is installed in a directory that is not on your PATH. There are three duplicate pip executables installed on my system:

  • /opt/homebrew/bin/python3
  • /Users/xxx/Library/Python/3.9/bin
  • /Applications/Xcode.app/Contents/Developer/usr/bin/python3

If you see this warning, you can add the following to your ~/.zshrc file:

export PATH="/opt/homebrew/bin/python3:$PATH"
